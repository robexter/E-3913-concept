## Publicação no GitHub Pages
1. Envie todos os arquivos para a raiz do repositório.
2. Em **Settings > Pages**, selecione `main` e `/(root)`.
3. Aguarde a publicação.
4. Abra o endereço HTTPS no celular.
5. Toque em **Instalar E-3913 concept**.

Se o prompt automático não aparecer:
- Android/Chrome: menu do navegador → **Instalar app** ou **Adicionar à tela inicial**.
- iPhone/iPad: **Compartilhar** → **Adicionar à Tela de Início**.
